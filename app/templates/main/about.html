About the Blogging Platform

A complete, production-ready, full-stack web application designed and built across an intensive 8-week engineering curriculum.

Project Objectives & Scope

The primary objective of this internship project is to build a modern, scalable, and secure blogging platform from scratch without relying on boilerplate CMS solutions. It demonstrates mastery across full-stack Python software engineering, relational database modeling, rich-text sanitization, modern CSS styling, and automated test-driven development.

Robust Security Architecture

Cryptographic Hashing

Passwords are salted and hashed using modern scrypt/PBKDF2 via Werkzeug. Plain text passwords are never stored in memory or on disk.

Bleach XSS Sanitization

All HTML content submitted via Quill.js is scrubbed through Bleach, stripping executable scripts, harmful attributes, and invalid styling.

CSRF Defense

Flask-WTF enforces synchronized cryptographic tokens on all HTTP POST/DELETE requests, blocking cross-site request forgery attacks.

Role & Owner Authorization

All article modification and deletion endpoints verify that the authenticated author strictly owns the target resource before execution.
